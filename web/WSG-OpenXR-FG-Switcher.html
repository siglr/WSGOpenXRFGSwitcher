More help with installation

Windows x64 and .NET 10 Desktop Runtime (x64) are required. If Windows asks for .NET, use the download link above and choose the Desktop Runtime. Extract the ZIP into a writable folder; do not run the app from inside the ZIP.

MSFS 2024 is detected automatically. For another game, use Add game… and select its executable. Use Mod folder… to choose where WSG installs managed mods.

For VectorXR, complete its official installer and any Windows administrator prompt. Close the VectorXR editor before applying changes in WSG. If an installation is interrupted, follow the app’s recovery instructions.

For custom launch scripts

If you already use a script to start your flight tools, WSG can fit into it. Close any existing WSG instance using Exit before running an apply command.

"WSG OpenXR FG Switcher.exe" --apply-default

This applies your saved default and exits, leaving the selected mod ready. Have your script wait for a successful result (exit code 0) before starting the game. The included README has a complete PowerShell example.

"WSG OpenXR FG Switcher.exe" --tray

This opens WSG in the tray. It applies a setup only if your saved Apply-on-launch option is enabled. The older --minimized and --start-minimized switches still work.

Questions? Find the details here.

How do per-game settings work?

Each WSG game preset remembers the selected mod, version and settings managed by WSG. For example, you can save a different frame rate or quality setting for each game. Selecting a preset does not apply it immediately: close your games and click Apply, or use your saved startup preset.

Only one setup is active at a time. OFXR activation is system-wide; VectorXR uses application profiles matched by executable name. Per-game presets do not create simultaneous independent configurations. Restart the game after applying changes; toggling VR mode alone is not enough.

Does this work only with MSFS 2024?

No. You can add another OpenXR game. Actual support and results depend on the chosen mod, runtime, headset and game. Headset testing is still pending for this preview, so compatibility is not guaranteed.

Does “Applied” mean frame generation is running?

Applied and Ready for next launch mean WSG has checked the saved setup. They do not confirm what is running in your headset. Launch the game and use the mod’s own tools to check its operation. The blue outline shows which tab you are editing; green identifies the applied setup.

Where are the more advanced mod settings?

Expand More options for additional controls supported by the selected version. For full settings, use the OFXR icon’s menu beside the Windows clock, or Start VectorXR app. WSG saves the controls it manages; other provider settings are preserved. Close the VectorXR editor and use Rescan setup after changing settings outside WSG.

Can I use VectorXR’s extra features with OFXR?

Yes, through the explicit option to keep VectorXR’s other features while its frame generation stays off. These combinations remain experimental. WSG normally uses one mod on its own for easier comparisons, and blocks known conflicts and simultaneous managed frame-generation providers.

Checks include supported saved settings for the OpenXR Toolkit / VectorXR turbo-mode conflict. WSG cannot measure every in-game toggle or runtime motion-smoothing setting. Review any compatibility messages and the provider’s documentation.

What do test notes record?

Your observations and any FPS figures you enter, together with the setup’s mod version, settings and OpenXR runtime. Try the same scene with each setup, then save what you noticed. You can export your notes to CSV for a spreadsheet. WSG does not measure performance or run benchmarks automatically.

What do Rescan, updates and recovery do?

Rescan setup checks for changes made outside WSG. Check for updates refreshes the mod list independently of WSG updates; you choose when to download and install new compatible mod versions. WSG app updates are automatic. They install when the app is idle and wait while you are playing or changing a setup.

Recover operation… helps resolve an interrupted switch, installation or removal. It is only available when needed and is not a general reset button. A cancelled or unfinished uninstall is not treated as a completed removal.

What happens when I close the window or choose Exit?

Closing or minimizing the window keeps WSG in the tray and pauses routine checks. Reopening refreshes the setup, and WSG checks again before making changes. An unfinished removal or an explicitly requested Exit may still need checks to finish.

Exit performs provider cleanup once games have closed; it does not silently interrupt a running session. The --apply-default script command instead exits with the selected mod still active, ready for your game. The startup options are independent and both are off by default; WSG never starts your game for you.

What gets removed when I clean stored files?

Completed recovery copies, cached downloads and unused presets for uninstalled, inactive mod versions. Installed mods, current presets and test notes are kept. Unfinished recovery data stays until the operation is resolved.

Use Data folder to open WSG’s files, stored under %LOCALAPPDATA%\WSG OpenXR FG Switcher. Mod removal is a separate action under Manage installation; VectorXR uses its official uninstaller.

Where do the mods come from?

The WSG download contains the switcher; the mods download separately from their official sources and remain unchanged. Downloads are checked against a signed catalog of reviewed versions and file hashes. WSG’s package and update signatures are separate from Windows publisher signing.

What if Windows or antivirus shows a warning?

Keep your protection enabled. If a file is flagged, report the exact warning and download checksum to WeSimGlide.

This development build does not carry an Authenticode publisher certificate. Signed package metadata checks package identity, but does not establish Windows publisher reputation or guarantee antivirus clearance.
